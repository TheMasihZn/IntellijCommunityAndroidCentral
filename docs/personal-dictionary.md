# masih's personal dictionary

Part of the context file (see [terminal-language.md §8](terminal-language.md#8-the-context-file)). The AI that
acts for masih reads this before interpreting anything he says or writes, and uses these words when it
speaks for him. Add a row whenever he coins or bends a word; never "correct" these words back.

| Word as masih uses it | Built from | Means | Use it for |
|---|---|---|---|
| تنظیمable (tanzim-able) | Persian تنظیم (setting) + English -able | configurable, can be set by the person | settings, syntax options |
| natije-giri (نتیجه‌گیری) | Persian, "drawing a conclusion" | implication: B is the result of A, so B waits for A; written `=>` (or `<=`) | the only reason one action waits for another |
| while (in a script) | English | **until**: keep going until the goal holds | `.while(Telegram.connection != Connected)` |
| action block | English | what programmers call a code block; actions inside run together | `{ … }` after `if` |
| `.name` folder (dot folder) | One UI folder naming | ordered alternatives; the first that succeeds wins | `.vpn` |
| `name()` | programming | start it; read aloud as "start name" | `vpn()` = "start VPN" |
| `.` with nothing after | punctuation | the script is finished ("bye-bye") | end of every script |
| `;` | punctuation | start this and go on; don't wait | between independent actions |
| first.script | file name | read as "the first script file" / «اسکریپت اول», never spelled out | naming files by meaning |
| seed script | — | what masih writes; the AI compiles it for each machine | `.script` files |
| co-launcher | — | a separate Lua launcher instance running as its own user | Launcher plan |
| فیلترشکن (filter-shekan) | Persian | VPN / anti-filter tool | `.vpn` |
